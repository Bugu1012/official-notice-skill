# 文件式格式

> 本文件规定通知采用的文件式红头格式完整要素，与信函式格式的区别，以及与 document-format-skill 的联动说明。

---

## 一、文件式与信函式的适用区分

| 维度 | 文件式 | 信函式 |
|------|--------|--------|
| 适用文种 | 通知、通报、报告、请示、批复、意见、纪要等 | 函 |
| 发文机关标志 | "×××文件"（红色大字居中） | 发文机关全称（红色，不加"文件"二字） |
| 发文字号位置 | 发文机关标志下空二行，居中 | 发文机关标志下空二行，居右 |
| 红色分隔线 | 有（武文线） | 有（武文线） |
| 签发人 | 上行文标注 | 一般不标注 |
| 版记 | 有（抄送、印发机关、印发日期） | 有 |

**通知一律使用文件式格式。**

---

## 二、版头

版头位于公文首页红色分隔线以上。

### 2.1 发文机关标志

- **内容：** 发文机关全称或规范化简称 + "文件"二字。如"×××市人民政府文件""×××局文件"。
- **字体：** 小标宋体（推荐），红色。
- **位置：** 居中排布，上边缘至版心上边缘为35mm。
- **字号：** 由发文机关确定，以醒目美观为原则。
- **联合行文：** 主办机关排列在前，也可只用主办机关标志。

### 2.2 发文字号

- **格式：** 机关代字 + 〔年份〕 + 序号 + "号"。如"×政发〔2025〕12号"。
- **字体：** 3号仿宋体字。
- **位置：** 发文机关标志下空二行，居中排布。
- **规则：**
  - 年份用六角括号〔〕括入，标全称。
  - 序号为阿拉伯数字，不加"第"字，不编虚位。
  - 联合行文只标注主办机关发文字号。

### 2.3 签发人

- **适用范围：** 上行文（报告、请示）必须标注；通知为下行文或平行文，一般不标注签发人。
- **格式：** "签发人"三字用3号仿宋体字，后标全角冒号，签发人姓名用3号楷体字。
- **位置：** 发文字号右侧（平行排布）。
- **注意：** 若通知确需标注签发人（如经授权代发的通知），格式同上。

### 2.4 份号、密级、紧急程度（按需）

| 要素 | 适用条件 | 格式 |
|------|----------|------|
| 份号 | 涉密公文 | 6位阿拉伯数字，顶格，版心左上角第一行 |
| 密级和保密期限 | 涉密公文 | 如"秘密★1年"，顶格，份号下一行 |
| 紧急程度 | 紧急公文 | "特急"或"加急"，顶格，密级下一行（无密级则在份号下一行） |

## 三、主体

主体位于红色分隔线以下、版记分隔线以上。

### 3.1 标题

- **格式：** 发文机关名称 + 关于 + 事由 + 的 + 文种（通知）。
- **示例：** ×××市人民政府关于开展安全生产大检查的通知
- **字体：** 2号小标宋体字。
- **位置：** 红色分隔线下空二行，居中排布。分一行或多行时，排列对称美观。
- **规则：**
  - 标题中除法规、规章名称加书名号外，一般不用标点符号。
  - 转发类通知标题可省略发文机关（因版头已有）。
  - 事由应简明扼要，概括通知核心内容。

### 3.2 主送机关

- **位置：** 标题下空一行，居左顶格。
- **字体：** 3号仿宋体字。
- **格式：** 机关全称或规范化简称。多个主送机关之间用逗号分隔（同级同类）或顿号分隔（不同类），最后一个机关名称后标全角冒号。
- **回行：** 仍顶格。
- **示例：**
  - 单一主送：各县（市、区）人民政府：
  - 多个主送：各县（市、区）人民政府，市政府各部门、各直属机构：

### 3.3 正文

- **字体：** 3号仿宋体字。
- **位置：** 主送机关名称下一行。
- **段落：** 每个自然段左空二字，回行顶格。
- **结构层次序数：**
  - 第一层：一、二、三、……（用顿号）
  - 第二层：（一）（二）（三）……（不加标点）
  - 第三层：1. 2. 3. ……（用下角点）
  - 第四层：（1）（2）（3）……（不加标点）
- **数字使用：** 按 GB/T 15835 执行（统计数据用阿拉伯数字，定型的词组用汉字）。

### 3.4 附件说明

- **位置：** 正文下空一行，左空二字。
- **格式：**

```
  附件：1. ×××实施方案
     2. ×××统计表
```

- **规则：**
  - "附件"二字后标全角冒号。
  - 多个附件用阿拉伯数字序号 + 下角点。
  - 附件名称不加书名号（法规、规章除外）。
  - 附件名称后不加标点。
  - 回行与上一行附件名称首字对齐。

### 3.5 发文机关署名

- **位置：** 正文（或附件说明）下适当位置，居右。
- **内容：** 发文机关全称或规范化简称。
- **字体：** 3号仿宋体字（实际中多为印章替代）。

### 3.6 成文日期

- **位置：** 发文机关署名下一行，居右（与署名对齐）。
- **格式：** 阿拉伯数字，年月日标全。如"2025年7月25日"。
- **规则：**
  - 月、日不编虚位（7月5日，不是07月05日）。
  - 以负责人签发日期为准；联合行文以最后签发日期为准。
  - 会议通过的文件以会议通过日期为准。

### 3.7 印章

- **要求：** 公文中有发文机关署名的，应当加盖印章。
- **盖法：** 印章端正、居中下压发文机关署名和成文日期（"骑年盖月"）。
- **联合行文：** 各发文机关都需盖章，主办机关印章在前。
- **例外：** 有特定发文机关标志的普发性公文和电报可以不加盖印章。

### 3.8 附注（按需）

- **位置：** 成文日期下一行，左空二字，加圆括号。
- **内容：** 如"（此件公开发布）""（联系人：×××，电话：×××）"。
- **字体：** 3号仿宋体字。

## 四、版记

版记位于公文末页底部。

### 4.1 抄送机关

- **位置：** 印发机关和印发日期之上一行。
- **格式：** 左右各空一字，"抄送"二字后标全角冒号，再列抄送机关名称。
- **字体：** 3号仿宋体字。
- **规则：**
  - 多个抄送机关之间用逗号分隔。
  - 最后一个抄送机关名称后标句号。
  - 回行时与冒号后的首字对齐。
- **示例：**
  - 抄送：市财政局、市审计局。

### 4.2 印发机关和印发日期

- **位置：** 末条分隔线之上（版记最后一行）。
- **格式：** 印发机关左空一字，印发日期右空一字。
- **字体：** 3号仿宋体字。
- **示例：**
  - ×××市人民政府办公室   2025年7月25日印发

### 4.3 分隔线

- 版记中各要素之间用分隔线隔开。
- 首条分隔线位于抄送机关之上（无抄送则在印发机关之上）。
- 末条分隔线位于印发机关和印发日期之下，与版心等宽。

## 五、标题格式详解

### 标准结构

**发文机关 + 关于 + 事由 + 的 + 文种**

| 组成部分 | 示例 | 说明 |
|----------|------|------|
| 发文机关 | ×××市人民政府 | 可省略（版头已有时） |
| 关于 | 关于 | 固定介词 |
| 事由 | 开展安全生产大检查 | 简明概括核心内容 |
| 的 | 的 | 固定助词 |
| 文种 | 通知 | 不可省略 |

### 特殊标题

| 情形 | 标题格式 | 示例 |
|------|----------|------|
| 转发通知 | 转发+原文件标题+的通知 | 转发省住建厅关于加强质量管理的通知 |
| 批转通知 | 批转+原文件标题+的通知 | 批转市安委办关于专项整治方案的通知 |
| 联合行文 | 主办机关+关于+事由+的+通知 | （或省略机关，版头体现） |
| 任免通知 | ×××关于×××等同志职务任免的通知 | 标题含"任免"字样 |

### 标题禁忌

- 不用标点符号（法规名称加书名号除外）。
- 不用"有关""相关"等模糊词替代具体事由。
- 不省略文种（必须出现"通知"二字）。
- 转发类标题避免"关于……的关于……的通知"嵌套。

## 六、主送机关位置和规范

### 位置

标题下空一行 → 居左顶格 → 最后标全角冒号 → 下一行开始正文。

### 规范要点

| 要点 | 说明 |
|------|------|
| 顶格 | 不缩进，回行仍顶格 |
| 全称或规范简称 | 不用非规范简称（如"市局"应写"市住房和城乡建设局"） |
| 排序 | 按机关性质和级别；同类按机构序列 |
| 标点 | 同类机关间用逗号，不同类用顿号，最后一个后标冒号 |
| 普发性 | 可用统称："各县（市、区）人民政府，市政府各部门、各直属机构" |
| 单一主送 | 只有一个主送机关时，直接写机关名称后标冒号 |

## 七、与信函式格式的差异对比表

| 对比项 | 文件式（通知用） | 信函式（函用） |
|--------|------------------|----------------|
| 发文机关标志 | "×××文件"，红色大字居中 | 发文机关全称（无"文件"二字），红色居中 |
| 发文字号位置 | 居中 | 居右 |
| 签发人 | 上行文标注（通知一般不标） | 一般不标注 |
| 标题 | 发文机关+关于+事由+的+通知 | 发文机关+关于+事由+的+函 |
| 主送机关 | 顶格，标题下空一行 | 同 |
| 正文 | 3号仿宋 | 同 |
| 收束语 | "请认真贯彻执行""请遵照执行"等 | "特此函达""即请函复""请予支持"等 |
| 印章 | 骑年盖月 | 同 |
| 版记 | 有 | 有 |
| 整体视觉 | 庄重、正式、权威感强 | 相对简洁、平等感 |

## 八、联动 document-format-skill 说明

### 联动场景

当通知写作完成后，需要排版输出为正式文件格式时，调用 document-format-skill 进行格式化。

### 联动接口

| 传递内容 | 说明 |
|----------|------|
| 通知正文（纯文本） | 含标题、主送、正文、附件说明、署名、日期 |
| 格式类型标记 | 固定为"文件式" |
| 发文机关标志文字 | 如"×××市人民政府文件" |
| 发文字号 | 如"×政发〔2025〕12号" |
| 附件列表 | 附件序号和名称 |
| 抄送机关 | 如有 |
| 印发机关和印发日期 | 如有 |
| 紧急程度/密级 | 如有 |

### 联动规则

1. 通知技能负责内容（写什么），document-format-skill 负责排版（怎么排）。
2. 通知技能输出的文本必须符合本文件规定的要素完整性，document-format-skill 不补充内容。
3. 若通知缺少必要格式要素（如无主送机关），应在通知技能环节补齐后再传递。
4. 附件的实际文件由用户另行准备，通知技能只标注附件名称。

### 排版参数（供 document-format-skill 参考）

| 参数 | 值 |
|------|------|
| 纸张 | A4（210mm × 297mm） |
| 版心 | 156mm × 225mm |
| 上边距 | 37mm（含发文机关标志区域） |
| 下边距 | 35mm |
| 左边距 | 28mm |
| 右边距 | 26mm |
| 正文行距 | 28磅（固定值） |
| 标题字体 | 2号小标宋体 |
| 正文字体 | 3号仿宋_GB2312 |
| 一级标题 | 3号黑体 |
| 二级标题 | 3号楷体_GB2312 |
| 页码 | 4号半角宋体阿拉伯数字，外侧居中 |

## 九、格式自检清单

完成通知排版后，逐项检查：

- [ ] 发文机关标志是否为红色、居中、含"文件"二字？
- [ ] 发文字号是否使用六角括号、无"第"字、无虚位？
- [ ] 标题是否完整（机关+关于+事由+的+通知）？
- [ ] 主送机关是否顶格、在标题下空一行、末尾有冒号？
- [ ] 正文每段是否左空二字？
- [ ] 结构层次序数是否正确（一、→（一）→1.→（1））？
- [ ] 附件说明是否在正文下空一行、左空二字、无书名号？
- [ ] 成文日期是否为阿拉伯数字、月日不编虚位？
- [ ] 抄送机关是否在版记部分、格式正确？
- [ ] 印发机关和印发日期是否在末条分隔线之上？
