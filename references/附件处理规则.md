# 附件处理规则

## 一、附件与正文的关系

通知按附件关系分为两大类：

### 1.1 附件为核心载体（发布性/批转性/转发性）

此类通知中，正文是"发布令"，附件才是实质内容：

| 类型 | 正文功能 | 附件功能 |
|---|---|---|
| 发布性 | 宣布印发某规章/制度/方案 | 承载规章/制度/方案全文 |
| 批转性 | 表态同意+要求执行 | 承载被批转的下级文件 |
| 转发性 | 传达要求+执行部署 | 承载被转发的上级/同级文件 |

正文结构极简（通常 1-3 句），核心信息量在附件中。

### 1.2 正文为核心载体（指示性/会议/任免/事务性）

此类通知无附件或附件为辅助材料：

| 类型 | 正文功能 | 附件情况 |
|---|---|---|
| 指示性 | 部署工作、提出要求 | 可有可无（如分工表、任务清单） |
| 会议 | 告知会议安排 | 可有（如参会回执、议程） |
| 任免 | 宣布人事决定 | 无 |
| 事务性 | 告知具体事务 | 可有（如名单、表格） |

## 二、附件标注格式

### 2.1 标准格式

附件说明位于正文之后、发文机关署名之前，左空二字编排：

```
附件：1.《×××管理办法》
      2.《×××实施方案》
      3. ×××名单
```

### 2.2 格式规则

- "附件"二字后标全角冒号。
- 多个附件用阿拉伯数字序号，序号后标下脚点（.）。
- 附件名称加书名号（规章、制度、方案、办法等规范性文件）或不加（名单、表格等）。
- 附件名称不加"附件"二字前缀（不写"附件：附件1.……"）。
- 附件名称后不加标点（不加句号）。
- 附件序号与正文中提及的序号一致。
- 回行时与上一行附件名称首字对齐。

### 2.3 正文中的附件引用

正文中提及附件时，使用规范表述：

- 发布性："现将《×××》印发给你们，请认真贯彻执行。"
- 批转性："国务院同意×××《关于×××的报告》，现转发给你们……"
- 转发性："现将《×××》转发给你们，请结合实际认真贯彻执行。"

## 三、多层转发标题简化规则

### 3.1 问题

层层转发导致标题嵌套过深：
> ×××关于转发《×××关于转发《×××关于×××的通知》的通知》的通知

### 3.2 简化规则

1. **省略中间层级**：只保留最顶层发文机关和最底层原始文件标题。
   - 简化为：×××关于转发×××关于×××工作的通知
2. **省略"的通知"**：被转发文件标题中的"的通知"可省略。
   - 简化为：×××关于转发×××做好×××工作的通知
3. **直转原文**：若中间层无实质增量要求，可直接转发原始文件。
4. **概括式标题**：用事由概括替代完整文件标题。
   - 简化为：×××关于做好×××工作的通知

### 3.3 简化原则

- 标题不超过两行为宜。
- 保留原始文件的核心事由。
- 不改变原意、不产生歧义。
- 正文中注明被转发文件的完整标题和发文字号。

## 四、附件常见类型

| 附件类型 | 典型名称 | 是否加书名号 |
|---|---|---|
| 规章/法规 | 《×××管理办法》《×××条例》 | 是 |
| 制度/规范 | 《×××工作制度》《×××操作规程》 | 是 |
| 方案/计划 | 《×××实施方案》《×××行动计划》 | 是 |
| 意见/办法 | 《关于×××的意见》《×××暂行办法》 | 是 |
| 名单 | ×××领导小组成员名单 | 否 |
| 表格/清单 | ×××任务分解表、×××项目清单 | 否 |
| 被转发文件 | 《×××关于×××的报告》 | 是 |
| 回执/表格 | 参会回执、报名表 | 否 |

## 五、技能边界

本技能对附件的处理原则：

1. **只标注，不起草**：技能负责在正文中正确引用附件、在附件说明处正确标注，但不负责起草附件内容本身。
2. **附件内容属于独立文种**：规章、制度、方案、办法等附件有各自的写作规范，不属于"通知写作"范畴。
3. **被转发文件原文照录**：批转性/转发性通知的附件为已有文件，不修改、不缩略、不改写。
4. **辅助性附件可提示结构**：对任务分解表、名单等辅助附件，可提示其结构框架，但不编造具体条目。
5. **审查时核验附件引用一致性**：正文提及的附件名称、序号必须与附件说明处完全一致。
