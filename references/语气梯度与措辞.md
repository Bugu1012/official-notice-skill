# 语气梯度与措辞

## 一、三档语气设计

通知的语气根据行政约束力分为三档。选择哪档取决于：发文机关与受文机关的关系、事项的强制程度、执行裁量空间。

| 档位 | 名称 | 约束力 | 典型场景 | 裁量空间 |
|------|------|--------|----------|----------|
| 第一档 | 强部署 | 必须执行，不可变通 | 安全生产、环保督察、疫情防控、法规实施 | 极小或无 |
| 第二档 | 中要求 | 应当执行，允许结合实际细化 | 工作推进、改革试点、专项任务 | 中等 |
| 第三档 | 弱告知 | 知悉即可，或参照执行 | 机构调整告知、信息发布、经验推广 | 大 |

---

## 二、第一档：强部署语气

### 标志词表（可用）

| 类别 | 词汇 |
|------|------|
| 强制动词 | 必须、务必、严禁、不得、一律、坚决、切实、严格 |
| 执行要求 | 贯彻执行、遵照执行、严格落实、不折不扣、令行禁止 |
| 时限约束 | 立即、即刻、限期、务必于X日前、不得迟于 |
| 问责表达 | 严肃追究、依规依纪依法、从严处理、绝不姑息 |
| 程度副词 | 坚决、切实、严格、全面、彻底 |
| 否定表达 | 严禁、不得、不准、不允许、杜绝 |

### 禁用词表

| 禁用 | 原因 | 替代 |
|------|------|------|
| 尽量 | 削弱强制性 | 必须、务必 |
| 争取 | 暗示可失败 | 确保、保证 |
| 原则上 | 留后门 | 删除，或改为"一律" |
| 一般情况下 | 暗示例外 | 删除 |
| 建议 | 无约束力 | 要求、责令 |
| 希望 | 无约束力 | 要求、务必 |
| 可以参考 | 无强制性 | 遵照执行 |
| 酌情 | 裁量过大 | 按照……执行 |

### 典型句式
- "各地区各部门必须……，不得……"
- "对……的，严肃追究有关责任人责任"
- "务必于20XX年X月X日前完成……"
- "严禁以任何形式……"

## 三、第二档：中要求语气

### 标志词表（可用）

| 类别 | 词汇 |
|------|------|
| 要求动词 | 应当、要、认真、抓紧、着力、积极、统筹 |
| 执行要求 | 认真组织实施、结合实际贯彻落实、抓好落实 |
| 推进表达 | 加快推进、有序推进、稳步推进、扎实推进 |
| 协调表达 | 统筹协调、协同推进、联动配合 |
| 程度副词 | 进一步、切实、充分、深入 |
| 引导表达 | 引导、推动、促进、带动 |

### 禁用词表

| 禁用 | 原因 | 替代 |
|------|------|------|
| 必须（过度使用） | 语气过重，不符合中档定位 | 应当、要 |
| 严禁 | 语气过重 | 不得、避免 |
| 仅供参考 | 削弱执行力 | 参照执行 |
| 最好 | 口语化 | 应当 |
| 大概 | 不精确 | 删除或给出具体标准 |
| 可能 | 不确定 | 删除或改为判断句 |

### 典型句式
- "各地区各部门要认真组织实施，结合实际制定具体方案"
- "要进一步加强……，着力解决……"
- "请结合实际，抓好贯彻落实"
- "由XX部门牵头，会同XX部门，统筹推进……"

## 四、第三档：弱告知语气

### 标志词表（可用）

| 类别 | 词汇 |
|------|------|
| 告知动词 | 现将……通知如下、予以公布、予以明确 |
| 知悉表达 | 请知悉、请予关注、供参考 |
| 参照表达 | 参照执行、参照办理、供工作中参考 |
| 中性表达 | 自X日起施行、自X日起启用、现予公布 |
| 事务表达 | 现将有关事项通知如下、特此告知 |

### 禁用词表

| 禁用 | 原因 | 替代 |
|------|------|------|
| 必须 | 语气过重 | 删除或改为"请" |
| 严肃追究 | 告知类无问责 | 删除 |
| 坚决 | 语气过重 | 删除 |
| 务必 | 语气过重 | 请 |
| 不得 | 告知类无禁止 | 删除 |

### 典型句式
- "现将有关事项通知如下"
- "自20XX年X月X日起，……"
- "请知悉"
- "供各地区各部门在工作中参考"

## 五、部署口吻 vs 套话的判断标准

### 判断公式

**合法部署 = 具体主体 + 具体动作 + 可验证标准**

**套话 = 无主体 + 无动作 + 放入任何文件都成立**

### 判断矩阵

| 维度 | 合法部署 | 套话 |
|------|----------|------|
| 主体 | "由市住建局牵头" | "有关部门" |
| 动作 | "完成全市老旧小区消防通道改造" | "加强安全管理" |
| 标准 | "20XX年X月底前，改造率不低于95%" | "取得明显成效" |
| 可验证 | 可检查、可量化、可追责 | 无法判断是否完成 |
| 专属性 | 仅适用于本文件语境 | 放入任何文件都通顺 |

### 快速检验法

将待检验句子抽出，问三个问题：
1. 能否回答"谁来做"？→ 不能则为套话
2. 能否回答"做到什么程度算完成"？→ 不能则为套话
3. 把句子放入另一份完全不同主题的通知，是否仍然通顺？→ 是则为套话

## 七、称谓规则

### 主送机关称谓

| 场景 | 正确称谓 | 错误称谓 |
|------|----------|----------|
| 国务院发至省级 | 各省、自治区、直辖市人民政府，国务院各部委、各直属机构 | 各省政府、各部委 |
| 省委发至市级 | 各市（州）党委，省委各部委，省级国家机关各部门 | 各市党委 |
| 省政府发至市级 | 各市（州）人民政府，省政府各部门、各直属机构 | 各市、各厅局 |
| 市政府发至县级 | 各县（市、区）人民政府，市政府各部门 | 各县、各局 |
| 部委发至省级对口 | 各省、自治区、直辖市及计划单列市XX厅（局） | 各省XX局 |

### 正文中的指代

| 场景 | 正确用法 | 错误用法 |
|------|----------|----------|
| 泛指所有受文者 | 各地区各部门 | 大家、各单位 |
| 特指某类主体 | 各设区市人民政府 | 各地 |
| 指代牵头部门 | 牵头单位 | 有关部门 |
| 指代配合部门 | 配合单位/成员单位 | 相关单位 |
| 自称 | 本机关/我部/我省 | 我们 |

### 称谓硬规则

1. 主送机关用全称或规范化简称，不得用口语化简称
2. 多个主送机关按党、政、军、群顺序排列
3. 同级机关按机构序列排列
4. 正文中首次出现用全称，之后可用规范简称
5. "各地区各部门"为国务院文件固定泛称，地方文件改为"各市（州）""各县（市、区）"
6. 不得在主送中使用"等"字（"各市政府等"→ 不合格）
