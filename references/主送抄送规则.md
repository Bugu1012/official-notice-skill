# 主送抄送规则

## 一、主送机关确定规则

### 1.1 基本原则

主送机关是通知的主要执行对象，即"需要办理或执行通知事项"的机关。确定主送机关的核心依据：

1. **行政目的**：通知要求谁执行、谁落实、谁知晓并行动。
2. **通知类型**：不同类型通知的主送范围有惯例。
3. **职权归属**：事项属于谁的职责范围。

### 1.2 按通知类型确定主送

| 通知类型 | 主送确定逻辑 | 典型主送范围 |
|---|---|---|
| 发布性 | 需要执行该规章/制度的全部下级机关 | 各省、自治区、直辖市人民政府，国务院各部委、各直属机构 |
| 指示性 | 需要落实工作部署的下级机关 | 按事项涉及范围确定（可窄可宽） |
| 批转性 | 需要执行被批转文件的全部机关 | 同发布性 |
| 转发性 | 需要执行被转发文件的全部机关 | 同发布性 |
| 会议 | 需要参会的单位 | 具体参会单位列表或"各有关单位" |
| 任免 | 任免涉及的机关和需知晓的机关 | 具体机关名称 |
| 事务性 | 需要办理该事务的具体机关 | 一个或少数几个具体机关 |

### 1.3 主送机关书写规则

- 使用机关全称或规范化简称。
- 多个主送机关之间用逗号分隔，最后一个用冒号收束。
- 同类机关可用统称（如"各省、自治区、直辖市人民政府"）。
- 主送机关在标题下空一行，左侧顶格编排。
- 主送机关名称中不使用"关于"。

### 1.4 普发性通知的主送

国务院普发性通知的标准主送：
> 各省、自治区、直辖市人民政府，国务院各部委、各直属机构：

省级政府普发性通知的标准主送：
> 各市（州）人民政府，省政府各部门、各直属机构：

## 二、抄送机关规则

### 2.1 抄送对象确定

抄送机关是"需要知晓通知内容但不需要直接执行"的机关：

- 上级机关（报备性质）。
- 相关但非直接执行的平级机关。
- 需要配合的下一级机关。
- 联合发文时的非主办机关的上级。

### 2.2 抄送书写规则

- 位于印发机关和印发日期之上，左右各空一字。
- "抄送"二字后标全角冒号。
- 多个抄送机关用逗号分隔，最后一个用句号。
- 回行时与冒号后的首字对齐。
- 抄送机关按党、政、军、群顺序排列。

### 2.3 抄送常见错误

- 将应主送的机关列为抄送（导致执行责任不清）。
- 将无需知晓的机关列入抄送（扩大知悉范围）。
- 抄送机关排序不规范。
- 遗漏应抄送的上级机关。

## 三、联合发文规则

### 3.1 联合发文条件

- 涉及多个机关职权范围的事项。
- 需要多个机关共同执行或配合。
- 单一机关发文无法覆盖全部执行主体。

### 3.2 排序规则

联合发文机关的排列顺序：

1. **党、政、军、群**：党委机关在前，政府机关在后，军队机关再次，群团组织最后。
2. **同级按序列**：同级机关按机构序列排列（如国务院部委按序列号）。
3. **主办机关在前**：同一层级中，主办机关排第一位。

### 3.3 发文字号

- 联合发文只标注主办机关的发文字号。
- 不标注所有联合发文机关的字号。
- 主办机关 = 排名第一位的机关。

### 3.4 联合发文的印章

- 所有联合发文机关均需加盖印章。
- 印章排列与机关排序一致。
- 主办机关印章在前（左）。

## 四、主送范围常见错误

| 错误类型 | 表现 | 正确做法 |
|---|---|---|
| 主送过宽 | 事务性通知主送"各省、自治区、直辖市人民政府" | 只主送直接相关机关 |
| 主送过窄 | 普发性规章只主送部分省份 | 覆盖全部执行主体 |
| 主送含上级 | 将上级机关列为主送 | 上级应列为抄送（报备） |
| 主送含自身 | 联合发文时将主办机关也列入主送 | 主办机关是发文方，不是主送对象 |
| 统称错误 | "各省人民政府"（缺自治区、直辖市） | 使用完整规范统称 |
| 简称不规范 | "各省市政府" | 使用"各省、自治区、直辖市人民政府" |

## 五、越级行文禁止

### 5.1 基本规则

- 行文关系根据隶属关系和职权范围确定。
- 一般不得越级行文（不跳过直接上级或直接下级）。
- 通知为下行文或平行文，主送对象应为直接下级或平级机关。

### 5.2 允许越级的例外

- 发生重大紧急情况（如自然灾害、突发公共事件）。
- 经多次请示直接上级未获答复。
- 上级机关指定越级上报或下达。
- 检举、控告直接上级机关。

### 5.3 越级行文时的处理

- 越级行文时必须同时抄送被越过的机关。
- 在正文中说明越级行文的原因。
- 事后补办正常行文程序。

### 5.4 通知场景中的越级问题

- 国务院可直发县级（普发性通知），但省级以下一般不越级。
- 省级部门通知一般主送市级对口部门，不直接发到县级。
- 确需越级时，抄送被越过的中间层级。
