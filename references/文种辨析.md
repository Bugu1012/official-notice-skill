# 文种辨析

## 一、通知 vs 通报

### 维度对比表

| 维度 | 通知 | 通报 |
|------|------|------|
| 核心功能 | 部署工作、发布文件、告知事项 | 表彰先进、批评错误、传达情况 |
| 时间指向 | 面向未来（要求做什么） | 面向过去（已发生的事） |
| 约束力 | 有执行要求，受文者须行动 | 以教育、警示为主，无具体执行任务 |
| 受文者角色 | 执行者 | 受教育者/被警示者 |
| 典型动词 | 部署、安排、要求、印发 | 表彰、批评、通报、学习 |
| 结构重心 | 任务+要求 | 事实+评价+号召/警示 |
| 结语特征 | "请认真贯彻执行" | "望引以为戒""号召学习" |

### 最常见误用

**误用：** 将工作部署写成通报。如"关于进一步加强安全生产工作的通报"——内容是部署未来工作，应为通知。

**判断方法：** 问"受文机关读完后需要做什么？"
- 需要开展具体工作 → 通知
- 需要学习/警醒/知晓 → 通报

### 边界案例

- "关于XX事故的通报"→ 通报（传达已发生事实+警示）
- "关于做好XX事故后续处置工作的通知"→ 通知（部署未来工作）
- 同一事件可能先发通报（告知事实），再发通知（部署整改）

## 二、通知 vs 决定

### 维度对比表

| 维度 | 通知 | 决定 |
|------|------|------|
| 核心功能 | 部署工作、告知事项 | 对重大事项作出决策和安排 |
| 事项性质 | 常规性、阶段性、操作性 | 重大性、全局性、不可逆性 |
| 变更难度 | 可调整、可补充、可废止后重发 | 一经作出，非经法定程序不得变更 |
| 决策层级 | 各层级均可使用 | 通常为较高层级机关 |
| 典型场景 | 工作部署、文件发布、会议安排 | 设立/撤销机构、重大奖惩、重大政策调整 |
| 语气 | 可强可中可弱 | 庄重、严肃、不可商量 |
| 篇幅 | 灵活 | 通常较短，但重大决定可较长 |

### 最常见误用

**误用一：** 将一般工作部署升格为决定。如"关于开展春季植树造林活动的决定"——常规性工作，应为通知。

**误用二：** 将重大不可逆决策降格为通知。如"关于撤销XX局的通知"——机构撤销属重大决策，应为决定。

**判断方法：** 问"这件事是否可以轻易改变？"
- 可以调整、补充、变通 → 通知
- 一经作出即具有终局性、不可逆性 → 决定

### 边界案例

- "关于成立XX工作领导小组的通知"→ 通知（临时性协调机构，可调整）
- "关于设立XX局的决定"→ 决定（正式机构设立，需法定程序）
- "关于表彰XX的决定"→ 决定（重大表彰）
- "关于表彰XX的通报"→ 通报（一般性表彰，以教育为主）

## 三、通知 vs 命令（令）

### 维度对比表

| 维度 | 通知 | 命令（令） |
|------|------|------------|
| 核心功能 | 部署工作、告知事项 | 依法发布规章、宣布强制执行措施 |
| 法律依据 | 一般行政职权 | 必须有明确法律授权 |
| 发文主体 | 各级机关均可 | 限于法定主体（国家主席、国务院总理、部委首长、县级以上政府） |
| 强制程度 | 行政约束力 | 法律强制力，不服从即违法 |
| 典型场景 | 工作部署、文件发布 | 发布行政法规、宣布戒严、动员令、嘉奖令 |
| 格式 | 标准公文格式 | 有专用格式（令号、签发人职务） |
| 使用频率 | 极高 | 极低 |

### 最常见误用

**误用：** 将一般性工作要求写成命令。如"关于严禁在河道采砂的命令"——一般行政管理事项，应为通知（或通告）。

**判断方法：** 问"是否有法律明确授权以命令形式发布？"
- 有法律授权 + 法定主体 + 法定事项 → 命令
- 一般行政管理 → 通知/通告

### 边界案例

- 国务院总理签署发布行政法规 → 命令（国务院令）
- 国务院部署行政法规实施工作 → 通知
- 宣布进入紧急状态 → 命令
- 部署防汛工作 → 通知

## 四、通知 vs 批复

### 维度对比表

| 维度 | 通知 | 批复 |
|------|------|------|
| 行文方向 | 下行（主动发文） | 下行（被动答复） |
| 触发条件 | 发文机关主动部署 | 必须先有下级请示 |
| 受文对象 | 可多个（普发） | 仅针对请示机关（一对一） |
| 内容范围 | 发文机关自主确定 | 限于请示事项 |
| 典型起笔 | "为……，现就……通知如下" | "你单位《关于……的请示》（X〔20XX〕X号）收悉" |
| 主送机关 | 可多个 | 仅一个（请示机关） |
| 独立性 | 独立发文，无需前置文件 | 依附于请示，无请示则无批复 |

### 最常见误用

**误用一：** 下级未请示，上级主动发文答复 → 应为通知，非批复。

**误用二：** 将批复普发多个机关 → 批复只能主送请示机关。若需多个机关知晓，用通知转发批复内容。

**判断方法：** 问"是否先有请示？"
- 有请示 → 批复
- 无请示，主动发文 → 通知

### 边界案例

- 省政府主动部署全省教育改革 → 通知
- 市教育局请示设立某学校，省教育厅答复 → 批复
- 省教育厅将批复内容告知其他市 → 通知（转发）

## 五、通知 vs 意见

### 维度对比表

| 维度 | 通知 | 意见 |
|------|------|------|
| 核心功能 | 部署执行 | 提出见解和处理办法 |
| 约束力 | 强制执行（指示性）或告知（事务性） | 指导性为主，允许参照执行 |
| 裁量空间 | 小（指示性）或无（发布性） | 较大，受文者可结合实际取舍 |
| 行文方向 | 下行 | 上行、下行、平行均可 |
| 典型措辞 | "必须""要""请认真执行" | "建议""供参考""参照执行" |
| 结构 | 按通知类型定 | 现状分析+指导思想+具体措施+保障 |
| 独立性 | 独立执行依据 | 常作为通知的附件被印发 |

### 最常见误用

**误用一：** 将强制性工作部署写成意见。如"关于加强城市管理的意见"——若内容全是"必须""不得"，实为通知。

**误用二：** 将指导性建议写成通知。如"关于推进乡村振兴的通知"——若内容全是"建议""可考虑"，实为意见。

**判断方法：** 问"受文机关能否不执行？"
- 不可不执行 → 通知
- 可参照、可结合实际取舍 → 意见

### 边界案例

- "关于印发《XX实施方案》的通知"→ 通知（发布性，方案为附件）
- "关于XX工作的指导意见"→ 意见（指导性）
- "国务院批转XX部关于XX意见的通知"→ 通知（批转性），附件为意见
- 意见被通知印发后，意见本身获得执行力，但文种仍为意见

## 六、通知 vs 函

### 维度对比表

| 维度 | 通知 | 函 |
|------|------|------|
| 行文方向 | 下行（有隶属关系） | 平行（无隶属关系） |
| 机关关系 | 上级对下级 | 不相隶属机关之间 |
| 约束力来源 | 行政隶属关系 | 协商、请求、告知 |
| 典型动词 | 要求、部署、安排、印发 | 商请、函告、请予支持、请予协助 |
| 语气 | 可命令、可要求 | 平等、协商、礼貌 |
| 主送关系 | 下级机关 | 同级或不相隶属机关 |
| 典型场景 | 部署工作、发布文件 | 商洽工作、询问答复、请求批准 |

### 最常见误用

**误用一：** 对不相隶属机关用通知。如市教育局向市财政局发文要求拨付经费，用"通知"→ 应为函（"关于商请拨付XX经费的函"）。

**误用二：** 对下级机关用函。如省政府向各市政府部署工作用"函"→ 应为通知。

**判断方法：** 问"发文机关与受文机关是否有隶属关系？"
- 有隶属（上对下）→ 通知
- 无隶属（平行或不相隶属）→ 函

### 边界案例

- 省政府 → 各市政府（部署工作）→ 通知（有隶属）
- 省教育厅 → 省财政厅（商请经费）→ 函（无隶属，平级）
- 省教育厅 → 各市教育局（部署工作）→ 通知（有业务指导关系）
- 某市政府 → 另一市政府（商洽合作）→ 函（无隶属）
- 邀请不相隶属机关参会 → 函（"关于邀请参加XX会议的函"）
- 邀请下级机关参会 → 通知（会议通知）

## 七、文种判断树

```
需要发一份公文
│
├─ 是否有下级机关的请示在先？
│   ├─ 是 → 【批复】
│   └─ 否 ↓
│
├─ 发文机关与受文机关是否有隶属关系（上对下）？
│   ├─ 否（平行/不相隶属）→ 【函】
│   └─ 是（上对下）↓
│
├─ 事项是否具有重大性、不可逆性（设立/撤销机构、重大奖惩、重大政策终局决定）？
│   ├─ 是 → 【决定】
│   └─ 否 ↓
│
├─ 是否需要法律明确授权、以法定主体发布（发布行政法规、宣布紧急状态）？
│   ├─ 是 → 【命令（令）】
│   └─ 否 ↓
│
├─ 核心目的是表彰先进/批评错误/传达已发生的情况（面向过去的教育警示）？
│   ├─ 是 → 【通报】
│   └─ 否 ↓
│
├─ 核心目的是提出指导性见解，受文者有较大裁量空间？
│   ├─ 是 → 【意见】
│   └─ 否 ↓
│
└─ 部署工作/发布文件/告知事项/人事任免 → 【通知】
    （再按通知内部七类细分）
```

## 八、质询式澄清触发条件

当用户提供的写作需求存在以下情况时，必须先澄清文种再动笔：

| 触发条件 | 澄清问题 | 示例 |
|----------|----------|------|
| 用户说"写个通知"但内容实为表彰/批评 | "内容是部署未来工作，还是表彰/批评已发生的事？后者应为通报。" | "写个通知表扬一下先进单位" |
| 用户说"写个通知"但涉及机构设立/撤销 | "这是正式机构调整（应为决定）还是临时协调机构（可用通知）？" | "写个通知把XX科撤了" |
| 用户说"写个通知"但受文者为不相隶属机关 | "贵单位与受文单位是上下级关系还是平级/不相隶属？后者应为函。" | "给财政局发个通知要经费" |
| 用户说"写个通知"但内容全是"建议""可考虑" | "这些内容是要求对方必须执行，还是仅供参考？后者应为意见。" | "写个通知建议各单位搞节能" |
| 用户说"写个通知"但无请示前置却要求答复 | "是否有下级请示在先？有则为批复，无则为通知。" | "回复一下他们的申请" |
| 用户说"写个通知"但涉及发布行政法规 | "这是发布行政法规（应为命令/令）还是印发一般规范性文件（通知）？" | "发个通知公布这个条例" |

### 澄清原则

1. 先判断是否真的需要澄清——若信息足够判断，直接按正确文种执行并说明理由
2. 澄清问题必须具体、封闭（是/否或二选一），不问开放式问题
3. 最多问1-2个问题，不连续追问
4. 若用户坚持用错误文种，说明风险但尊重用户决定（用户指令优先）

## 九、综合辨析速查表

| 易混组 | 一句话判断 | 关键区分词 |
|--------|------------|------------|
| 通知 vs 通报 | 面向未来做事=通知；面向过去教育=通报 | 部署/要求 vs 表彰/批评/传达 |
| 通知 vs 决定 | 可调整=通知；不可逆=决定 | 安排/推进 vs 设立/撤销/终局 |
| 通知 vs 命令 | 一般行政=通知；法定强制=命令 | 要求/请 vs 令/宣布 |
| 通知 vs 批复 | 主动发=通知；被动答=批复 | 现就……通知 vs 你单位请示收悉 |
| 通知 vs 意见 | 必须执行=通知；参照执行=意见 | 必须/要 vs 建议/供参考 |
| 通知 vs 函 | 有隶属=通知；无隶属=函 | 要求/部署 vs 商请/函告 |
