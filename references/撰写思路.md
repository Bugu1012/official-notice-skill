# 撰写思路

## 一、起草前的思考框架

### 三问定位法

起草任何通知前，必须依次回答三个问题：

**第一问：行政目的是什么？**
- 这份文件要解决什么具体问题？
- 发文机关期望受文机关做出什么具体行动？
- 如果不发这份文件，会产生什么后果？
- 目的必须具体到可验证的行为变化，而非抽象的"加强""提高"

**第二问：读者是谁？**
- 主送机关的层级、职能、执行能力如何？
- 读者最关心什么？（任务边界、资源支持、时限要求、问责风险）
- 读者可能产生什么疑问或抵触？
- 读者是否需要上级协调才能完成任务？

**第三问：硬约束有哪些？**
- 上位文件是否已有明确规定？（不得突破）
- 发文机关权限边界在哪里？（不得越权）
- 时限、预算、编制等刚性约束是什么？
- 是否涉及多部门职责交叉？（需会签）

### 思考框架应用示例

| 问题 | 错误回答 | 正确回答 |
|------|----------|----------|
| 行政目的 | "加强安全生产工作" | "确保20XX年X月底前完成全省危化品企业安全风险评估" |
| 读者 | "各市政府" | "各设区市政府分管副市长及应急管理局，需协调工信、交通部门" |
| 硬约束 | "按上级要求办" | "依据国发〔20XX〕X号第三条，评估经费由省级财政专项列支" |

## 二、谋篇布局原则

### 原则一：目的决定结构

- 部署工作 → 五段式（指示性）
- 赋予效力 → 一句式（发布性）
- 传递文件 → 一至三句（批转/转发性）
- 告知信息 → 要素清单（会议/事务性）
- 宣布人事 → 固定格式（任免）

不得用复杂结构写简单事项，也不得用简单结构承载复杂部署。

### 原则二：逻辑链完整

指示性通知的逻辑链：
```
为什么做（依据）→ 做成什么样（目标）→ 做什么（任务）→ 靠什么做（保障）→ 做不好怎么办（督查）
```

每一环缺失都会导致文件失效：
- 缺依据 → 合法性不足，下级可质疑
- 缺目标 → 执行无方向，无法考核
- 缺任务 → 文件空转，无法落地
- 缺保障 → 任务悬空，无资源支撑
- 缺督查 → 无约束力，执行衰减

### 原则三：信息密度递减

- 第一段（依据）：信息密度最高，每句都有制度含义
- 第二段（总要求）：密度次高，原则性表述
- 第三段（任务）：密度适中，操作性表述
- 第四段（保障）：密度较低，支撑性表述
- 第五段（督查）：密度最低，程式性表述

### 原则四：一段一旨

每段只承载一个核心功能。发现一段内同时出现"背景+任务+要求"时，必须拆分。

## 三、从依据到部署的展开逻辑

### 依据的三种来源

1. **文件依据：** 上位文件明确要求"各地制定实施方案"
   - 展开方式：引用文号 → 摘录核心要求 → 细化为本地任务
2. **会议依据：** 某次会议作出部署
   - 展开方式：引述会议精神 → 提炼核心部署 → 转化为具体安排
3. **现实依据：** 问题倒逼、形势需要
   - 展开方式：描述问题/形势 → 论证紧迫性 → 提出应对措施

### 展开的递进逻辑

```
依据（为什么）
  ↓ 逻辑推导
目标（做到什么程度）
  ↓ 目标分解
任务（具体做什么）
  ↓ 任务分配
责任（谁来做）
  ↓ 责任落实
保障（用什么条件做）
  ↓ 保障到位
督查（做不好怎么办）
```

每一步必须能回答"这一步不做，下一步是否还能成立"。若答案为否，则逻辑链完整。

## 四、指示性通知的"总-分-总"展开

### 总（第一段+第二段）

- 第一段建立"为什么"的合法性
- 第二段建立"做到什么程度"的方向感
- 两段合计为全文定调，后续所有段落不得偏离此调

### 分（第三段+第四段）

- 第三段是全文重心，篇幅占比应达50%-70%
- 任务分解遵循MECE原则（相互独立、完全穷尽）
- 每项任务内部结构：任务名称 → 具体内容 → 责任主体 → 完成时限
- 第四段为任务提供外部条件，不重复任务本身

### 总（第五段）

- 收束全文，建立闭环
- 将"部署-执行-检查"形成管理闭环
- 语气从部署转为约束，体现刚性

### 常见展开错误

| 错误 | 表现 | 修正 |
|------|------|------|
| 总分脱节 | 总要求说"绿色发展"，任务全是"经济增长" | 任务必须逐条对应总要求 |
| 分而不全 | 有任务无保障，或有保障无督查 | 五段缺一不可 |
| 总而不精 | 第一段铺陈500字背景 | 依据段控制在3句以内 |
| 分而重叠 | 两项任务实质相同，仅措辞不同 | 合并或明确区分边界 |

## 五、批转/转发的"极简正文"原则

### 核心原则：正文是"信封"，附件是"信"

批转性、转发性通知的正文功能仅限于：
1. 说明传递动作（"批转""转发"）
2. 表明态度（"同意""请认真执行"）
3. 必要时补充少量本地化要求

### 极简正文的边界

**可以写的：**
- 批转/转发决定
- "请认真贯彻执行"等执行要求
- "结合本地实际"等适应性提示
- 极少量补充要求（不超过2条，每条不超过1句）

**不可以写的：**
- 对附件内容的摘要或解读
- 独立的工作部署
- 背景分析和形势判断
- 与附件无关的其他事项

### 判断标准

写完正文后自问：如果删掉附件，正文是否还有独立存在价值？
- 若答案为"否"→ 正确（正文依附于附件）
- 若答案为"是"→ 错误（正文承载了过多独立内容，应改为指示性通知）

## 六、会议通知的"要素完备"原则

### 核心原则：受文者仅凭此文件即可准确参会

不需要打电话确认、不需要查其他文件、不需要猜测任何信息。

### 完备性自检清单

起草完成后逐项核对：
- [ ] 会议时间是否精确到日（必要时到时分）？
- [ ] 会议地点是否有具体地址（非仅"市政府"）？
- [ ] 参会人员范围是否明确到职务/单位？
- [ ] 会议内容/议题是否清晰？
- [ ] 是否需要提交材料？提交什么？何时提交？
- [ ] 异地参会是否需要报到？报到时间地点？
- [ ] 费用如何承担？
- [ ] 联系人和联系方式是否提供？
- [ ] 是否有特殊要求（着装、保密、不得代会等）？

### 常见缺失

- 只写"近期召开"不写具体日期 → 不合格
- 只写"各单位负责人"不写哪一级负责人 → 不合格
- 只写"市政府会议室"不写具体哪个会议室 → 视情况不合格
- 不写联系人 → 建议补充

## 七、常见谋篇错误

### 错误一：大帽子小身子

**表现：** 第一段用500字铺陈宏观背景（"党的二十大指出……新时代……新征程……"），正文任务只有3条共200字。

**修正：** 背景压缩至2-3句，直接引出具体依据。篇幅重心放在任务段。

### 错误二：有部署无主体

**表现：** "要加强组织领导""要完善工作机制""要强化资金保障"——全是"要"字句，无一句说明谁来做。

**修正：** 每项任务必须绑定责任主体。"由市委组织部牵头，市人社局配合，于20XX年X月底前完成……"

### 错误三：结构错配

**表现：** 转发国务院文件时，正文写了800字的本地部署。

**修正：** 转发类正文不超过3句。若确需大量本地化部署，改为指示性通知，将国务院文件作为依据引用而非附件转发。

### 错误四：逻辑断裂

**表现：** 总要求提出"到2025年实现全覆盖"，但任务段无任何时限安排，保障段无经费来源。

**修正：** 目标→任务→保障→督查形成闭环，每个目标都有对应任务，每个任务都有资源和时限。

### 错误五：层次混乱

**表现：** 一级标题下混入操作细节，或操作细节与原则性表述并列。

**修正：** 原则归"总要求"段，操作归"任务"段。同一层级内的条目必须抽象程度一致。

### 错误六：兜底滥用

**表现：** 将明显属于指示性、发布性的通知归为"事务性通知"，规避严格的结构要求。

**修正：** 严格按判断流程图确定类型。事务性通知仅用于真正不属于前六类的单一事务。
