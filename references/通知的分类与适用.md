# 通知的分类与适用

## 一、七种通知类型详解

### 1. 指示性通知

**定义：** 上级机关对下级机关部署工作、阐明工作活动的指导原则、提出工作要求的公文。是通知中使用频率最高、篇幅最长、结构最复杂的类型。

**适用场景：**
- 部署全局性或专项工作（如安全生产、乡村振兴、教育改革）
- 阐明某项工作的指导思想、基本原则和总体要求
- 提出具体工作任务、措施和时限要求
- 对已有政策进行细化落实安排

**判断标准：**
- 发文机关对受文机关有直接领导或业务指导关系
- 内容包含明确的工作部署、任务分解、责任分工
- 受文机关需要据此开展具体工作行动
- 通常有"现就……通知如下"的起笔标志

**与其他类型的区分：**
- 与发布性通知：指示性通知部署"做什么、怎么做"；发布性通知仅宣布某文件生效
- 与意见：指示性通知具有强制执行力；意见侧重指导性、参考性
- 与决定：指示性通知部署常规性工作；决定针对重大事项、不可逆决策

**公开可得性：** 国务院及各部委官网"政策文件"栏目大量公开，如国发〔2024〕系列文件。

---

### 2. 发布性通知

**定义：** 用于发布行政法规、规章、规范性文件，使其产生效力的公文。正文极短，核心功能是"赋予附件法律效力"。

**适用场景：**
- 发布行政法规（国务院令配套通知）
- 发布部门规章（部令配套通知）
- 发布规范性文件、管理办法、实施细则
- 发布标准、规范、规程

**判断标准：**
- 正文核心动作为"发布""印发""公布"
- 必有附件（被发布的法规/规章/文件全文）
- 正文通常仅1-2句话
- 不含具体工作部署或任务分解

**与其他类型的区分：**
- 与指示性通知：发布性通知不部署工作，仅赋予文件效力
- 与批转性通知：发布性通知发布的是本机关制定的文件；批转性通知批转的是下级机关的文件
- 与转发性通知：发布性通知的附件是原创性法规；转发性通知转发的是上级或不相隶属机关的文件

**公开可得性：** 极高。国务院公报、各部委官网均有大量"关于印发《XXX》的通知"。

---

### 3. 批转性通知

**定义：** 上级机关将下级机关的公文（报告、意见、方案等）加批语后转发给更大范围执行的公文。体现上级对下级文件的认可和推广。

**适用场景：**
- 国务院批转各部委的工作报告、实施方案
- 省政府批转厅局的工作意见
- 上级机关认为下级文件具有普遍推广价值

**判断标准：**
- 正文含"批转""同意"等批准性动词
- 附件为下级机关的原文件
- 发文机关级别高于附件原发文机关
- 批转后执行范围扩大到原发文机关之外

**与其他类型的区分：**
- 与转发性通知：批转是"上对下"的认可推广；转发是平级传递或"下传上"的告知
- 与发布性通知：批转的附件是他人（下级）的文件；发布的附件是本机关的文件
- 与指示性通知：批转性通知正文极短（≤3句）；指示性通知有完整部署结构

**公开可得性：** 高。"国务院批转XXX关于XXX的通知"在政府公报中常见。

---

### 4. 转发性通知

**定义：** 将上级机关、不相隶属机关的公文转发给下级机关执行或参照执行的公文。核心功能是"传递"而非"创造"。

**适用场景：**
- 转发上级机关的文件要求下级执行
- 转发不相隶属机关的文件供参照
- 多级转发（省转国务院文件、市转省文件）
- 联合转发多个机关的文件

**判断标准：**
- 正文含"转发""现将……转发给你们"等传递性动词
- 附件为上级或不相隶属机关的原文件
- 发文机关与附件原发文机关为同级或下级关系
- 可附加少量补充要求

**与其他类型的区分：**
- 与批转性通知：转发不含"批准"意味，仅传递；批转含上级认可
- 与指示性通知：转发性通知正文极简；指示性通知有独立部署内容
- 与发布性通知：转发的文件非本机关原创

**公开可得性：** 极高。各级政府"转发国务院/省政府XXX的通知"数量庞大。

---

### 5. 会议通知

**定义：** 告知有关单位或人员参加会议的公文。以要素完备为第一要求，确保受文者能据此准确参会。

**适用场景：**
- 召开工作会议、专题会议、座谈会
- 召开培训会、研讨会、评审会
- 召开视频会议、电话会议
- 召开联席会议、协调会

**判断标准：**
- 核心目的为告知会议信息
- 必含时间、地点、参会人员、会议内容等要素
- 不含工作部署或任务分解
- 可能有报到时间、材料准备等附加要求

**与其他类型的区分：**
- 与指示性通知：会议通知仅告知开会信息；指示性通知部署工作
- 与事务性通知：会议通知有固定要素清单；事务性通知事项更杂
- 与函：有隶属关系用通知；无隶属关系邀请参会用函

**公开可得性：** 中等。内部会议通知多为内部文件；公开性会议（如听证会）通知可在官网查到。

---

### 6. 任免通知

**定义：** 宣布人事任免决定的公文。格式最为固定，内容最为简短，不含任何工作部署或要求。

**适用场景：**
- 宣布干部任命（经组织程序决定后）
- 宣布干部免职
- 宣布聘任、解聘
- 宣布职务调整

**判断标准：**
- 正文仅含任免决定本身
- 有明确的任免依据（"经XX研究决定""经XX批准"）
- 无工作部署、无执行要求、无结语
- 格式固定："任命XXX为XXX""免去XXX的XXX职务"

**与其他类型的区分：**
- 与决定：任免通知宣布已定事项；决定用于重大人事安排（如设立机构）
- 与命令：国家主席/国务院总理用命令（令）任免；一般机关用通知
- 与事务性通知：任免通知格式完全固定；事务性通知有灵活性

**公开可得性：** 高。各级政府"关于XXX等同志职务任免的通知"在官网公开。

---

### 7. 事务性通知

**定义：** 处理日常事务性工作的通知。涵盖不属于上述六类的各类告知、安排事项。是兜底类型。

**适用场景：**
- 机构设立、撤销、合并、更名
- 启用、废止印章
- 变更办公地址、联系方式
- 节假日安排、值班安排
- 经费、资产、档案等事务安排
- 检查、考核、评比安排

**判断标准：**
- 不属于指示性、发布性、批转性、转发性、会议、任免中的任何一种
- 内容为具体事务性安排
- 有明确的事由和具体事项
- 可能有执行要求但无系统性工作部署

**与其他类型的区分：**
- 与指示性通知：事务性通知处理单一事务；指示性通知部署系统性工作
- 与会议通知：事务性通知事项不限于开会
- 与任免通知：事务性通知有灵活性结构；任免通知完全固定

**公开可得性：** 中等。机构调整、印章启用等通知在官网可查；内部事务通知多为内部文件。

---

## 二、类型判断流程图

```
收到/需起草一份通知
│
├─ 正文是否宣布人事任免？
│   ├─ 是 → 【任免通知】
│   └─ 否 ↓
│
├─ 正文是否仅告知会议信息（时间/地点/人员/议题）？
│   ├─ 是 → 【会议通知】
│   └─ 否 ↓
│
├─ 正文核心动作是否为"发布/印发"本机关制定的法规、规章、规范性文件？
│   ├─ 是 → 【发布性通知】
│   └─ 否 ↓
│
├─ 正文核心动作是否为"批转"下级机关的文件？
│   ├─ 是 → 【批转性通知】
│   └─ 否 ↓
│
├─ 正文核心动作是否为"转发"上级或不相隶属机关的文件？
│   ├─ 是 → 【转发性通知】
│   └─ 否 ↓
│
├─ 正文是否包含系统性工作部署（任务分解+责任分工+保障措施）？
│   ├─ 是 → 【指示性通知】
│   └─ 否 ↓
│
└─ 以上均不符合 → 【事务性通知】
```

**判断优先级说明：** 任免 > 会议 > 发布 > 批转 > 转发 > 指示 > 事务。先排除格式最固定的类型，再判断内容复杂度最高的类型，最后兜底。

## 三、易混类型对比表

| 对比组 | 核心区别 | 判断关键 | 常见误判 |
|--------|----------|----------|----------|
| 指示性 vs 发布性 | 部署工作 vs 赋予文件效力 | 正文是否有任务分解和措施要求 | 将"印发+少量要求"误判为指示性 |
| 指示性 vs 意见 | 强制执行 vs 指导参考 | 受文机关是否有裁量空间 | 将含"参照执行"的文件误判为意见 |
| 批转 vs 转发 | 上级认可下级 vs 传递他人文件 | 发文机关与附件原机关的层级关系 | 将转发上级文件误写为批转 |
| 发布 vs 批转 | 本机关原创 vs 下级机关原创 | 附件的原始制定者是谁 | 将印发本机关方案误写为批转 |
| 发布 vs 转发 | 本机关制定 vs 上级/平级制定 | 附件来源方向 | 将转发国务院文件误写为印发 |
| 会议 vs 事务性 | 仅告知开会 vs 处理其他事务 | 事项是否仅为"开会" | 将含培训安排的通知误判为会议通知 |
| 任免 vs 事务性 | 纯人事任免 vs 其他事务 | 内容是否仅为职务变动 | 将含机构调整+人事安排的通知误判为任免 |
| 指示性 vs 事务性 | 系统性部署 vs 单一事务 | 是否有完整的"总-分-总"结构 | 将单一事项安排误升为指示性通知 |

---

## 四、补充判断规则

1. **一文一事原则：** 一份通知原则上只处理一类事项。若同时涉及工作部署和人事任免，应拆分为两份文件。
2. **就高不就低原则：** 若内容同时符合两种类型特征，选择约束力更强、格式要求更严格的类型。
3. **附件决定类型：** 发布性、批转性、转发性通知的类型由附件来源决定，而非正文措辞。
4. **层级关系决定动词：** 上对下用"批转"，平级或下对上用"转发"，本机关原创用"发布/印发"。
5. **兜底审慎原则：** 事务性通知是兜底类型，使用前必须确认不属于前六种。
