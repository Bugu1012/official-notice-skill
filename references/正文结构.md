# 正文结构

## 一、结构总览

| 类型 | 结构模型 | 典型篇幅 | 段落数 |
|------|----------|----------|--------|
| 指示性通知 | 五段式（背景依据→总体要求→重点任务→组织保障→督促检查） | 2000-8000字 | 5大段+若干分层 |
| 发布性通知 | 发布决定+执行要求 | 50-150字 | 1-2句 |
| 批转性通知 | 批转决定+执行要求 | 50-200字 | 不超过3句 |
| 转发性通知 | 转发决定+补充要求 | 50-200字 | 不超过3句 |
| 会议通知 | 要素清单式 | 200-600字 | 3-6段 |
| 任免通知 | 固定格式 | 30-100字 | 1-3句 |
| 事务性通知 | 事由+事项+要求 | 200-800字 | 3-5段 |

---

## 二、指示性通知：五段式结构

### 结构模型

```
第一段：背景与依据
第二段：总体要求
第三段：重点任务（可分若干层次）
第四段：组织保障
第五段：督促检查
```

### 各段职责与规则

**第一段：背景与依据**
- 职责：说明为什么发这个通知，建立合法性和紧迫性
- 内容要素：政策依据（上位文件/会议精神）+ 现实背景（问题/形势）+ 目的（"为……"）
- 典型篇幅：150-400字
- 硬规则：
  - 必须引用具体文件名称及文号，不得泛泛而谈
  - "为……"目的句置于段首或段尾，不置于中间
  - 背景描述不超过3句，避免铺陈过长
  - 依据引用按层级排列：中央→国务院→部委→地方

**第二段：总体要求**
- 职责：明确指导思想、基本原则、工作目标
- 内容要素：指导思想（1-2句）+ 基本原则（3-5条）+ 工作目标（可量化）
- 典型篇幅：300-800字
- 硬规则：
  - 指导思想必须与第一段依据逻辑衔接
  - 基本原则用"坚持……"句式，每条不超过2句
  - 工作目标尽量量化（"到20XX年，实现……"）
  - 不得在此段展开具体措施（措施归第三段）

**第三段：重点任务**
- 职责：分解具体工作任务，明确责任主体和时限
- 内容要素：若干项任务，每项含"做什么+谁来做+怎么做+何时完成"
- 典型篇幅：800-5000字（视任务复杂度）
- 硬规则：
  - 每项任务必须有明确责任主体（"由XX部门牵头，XX部门配合"）
  - 任务编号用"（一）（二）（三）"，子项用"1. 2. 3."
  - 任务之间不重叠、不遗漏，逻辑并列或递进
  - 禁止出现无主体的任务（"要加强……"无主语=不合格）
  - 时限表述具体（"20XX年X月底前"而非"尽快"）

**第四段：组织保障**
- 职责：确保任务落实的支撑条件
- 内容要素：组织领导（领导小组/专班）+ 经费保障 + 政策支持 + 协调机制
- 典型篇幅：200-600字
- 硬规则：
  - 必须明确领导机构或牵头负责人层级
  - 经费保障须说明来源渠道
  - 不得与第三段任务内容重复

**第五段：督促检查**
- 职责：建立跟踪问效机制
- 内容要素：督查方式 + 考核机制 + 问责条款 + 报告制度
- 典型篇幅：150-400字
- 硬规则：
  - 必须明确督查主体和频次
  - 问责条款须有具体情形（"对……的，依规依纪追究责任"）
  - 报告制度须明确报送对象和时限
  - 此段为最后一段，之后不加"特此通知"等结语

## 三、发布性通知：极简结构

### 结构模型

```
发布决定（1句）+ 执行要求（0-1句）
```

### 标准格式

```
现将《XXX》印发给你们，请认真贯彻执行。
```

或：

```
《XXX》已经XX会议审议通过，现予发布，自20XX年X月X日起施行。
```

### 硬规则
- 正文不超过2句
- 第一句必须包含：文件全称 + 发布动词（"印发""发布""公布"）
- 第二句为执行要求或施行日期，可省略
- 不得在正文中展开文件内容摘要
- 不得添加背景说明或工作部署
- 附件为被发布文件全文

## 四、批转性通知：极简结构

### 结构模型

```
批转决定（1句）+ 评价/认可（0-1句）+ 执行要求（1句）
```

### 标准格式

```
国务院同意XX部《关于XXX的报告》，现转发给你们，请认真贯彻执行。
```

或：

```
XX省人民政府同意省XX厅《关于XXX的实施意见》，现批转给你们，请结合实际，认真组织实施。
```

### 硬规则
- 正文不超过3句
- 第一句必须包含：批准动词（"同意""批准"）+ 原文件制定机关 + 文件名称
- 必须使用"批转"而非"转发"
- 执行要求用"请认真贯彻执行""请结合实际组织实施"
- 不得在正文中重复附件内容
- 不得添加额外工作部署

---

## 五、转发性通知：极简结构

### 结构模型

```
转发决定（1句）+ 补充要求（0-2句）
```

### 标准格式

```
现将《国务院关于XXX的通知》（国发〔20XX〕X号）转发给你们，请认真贯彻执行。
```

或（含补充要求）：

```
现将《XXX》转发给你们，请认真贯彻执行。结合我省实际，提出以下要求：一、……二、……
```

### 硬规则
- 无补充要求时不超过1句；有补充要求时不超过3句（不含补充要求展开）
- 第一句必须包含：原发文机关 + 原文件名称 + 原文号 + "转发"
- 不得使用"批转"（除非发文机关确为上级且含批准意味）
- 补充要求仅限"结合本地实际"的操作性细化，不得另起炉灶
- 多级转发时，可省略中间层级，直接引用最原始文件

## 六、会议通知：要素清单式结构

### 结构模型

```
第一段：会议目的/依据（1-2句）
第二段：会议要素（时间、地点、内容、参会人员）
第三段：有关要求（报到、材料、纪律等）
```

### 必备要素清单

| 要素 | 是否必备 | 说明 |
|------|----------|------|
| 会议名称 | 必备 | 全称，与标题一致 |
| 会议时间 | 必备 | 精确到日，必要时精确到时 |
| 会议地点 | 必备 | 具体地址，必要时附交通指引 |
| 会议内容/议题 | 必备 | 至少概括性说明 |
| 参会人员 | 必备 | 明确范围（职务/单位/人数） |
| 报到时间地点 | 视需要 | 异地会议必备 |
| 材料准备 | 视需要 | 需提交材料时必备 |
| 费用说明 | 视需要 | 涉及差旅时说明 |
| 联系方式 | 建议有 | 联系人+电话 |
| 纪律要求 | 视需要 | 保密会议、大型会议 |

### 硬规则
- 时间必须用公历全称（"20XX年X月X日"），不用"下周""近期"
- 参会人员范围必须明确到职务层级或具体单位
- 不得遗漏任何必备要素
- 要素排列顺序固定：时间→地点→内容→人员→要求
- 结尾可用"请准时参加"或"请依时出席"，不用"特此通知"

## 七、任免通知：固定格式结构

### 结构模型

```
任免依据（1句）+ 任免决定（N句）
```

### 标准格式

**任命：**
```
经XX研究决定：
任命XXX为XXX（职务全称）。
```

**免职：**
```
经XX研究决定：
免去XXX的XXX（职务全称）职务。
```

**任免混合：**
```
经XX研究决定：
任命XXX为XXX；
免去XXX的XXX职务。
```

### 硬规则
- 无结语（不写"特此通知"）
- 无执行要求（不写"请遵照执行"）
- 无背景说明（不写"因工作需要"）
- 职务必须用全称，与"三定方案"一致
- 多人任免按职务高低排列
- 任免依据必须写明决定机关（"经国务院研究决定""经XX党组会议研究决定"）
- 不加任何评价性语言（不写"该同志政治素质好"）

## 八、事务性通知：三段式结构

### 结构模型

```
第一段：事由（为什么发这个通知）
第二段：事项（具体安排是什么）
第三段：要求（需要受文者做什么）
```

### 各段职责

**第一段：事由**
- 说明发文原因和依据
- 典型句式："根据……""因……""为……"
- 篇幅：1-3句

**第二段：事项**
- 具体事务安排
- 可分项列明（"一、……二、……"）
- 篇幅：视事项复杂度，100-500字

**第三段：要求**
- 执行要求或配合要求
- 典型句式："请……""望……"
- 篇幅：1-3句
- 可用"特此通知"作结（非必须）

### 硬规则
- 事由必须具体，不得泛化（"因办公地址搬迁"而非"因工作需要"）
- 事项必须可操作（有时间节点、有具体对象、有明确内容）
- 不得在事务性通知中夹带工作部署
- 单一事务一文，不合并多个无关事项

---

## 九、通用结构规则

1. **标题与正文对应：** 标题中的事由必须在正文第一段得到呼应。
2. **主送与内容匹配：** 主送机关必须是正文中任务的执行主体。
3. **附件与正文衔接：** 正文中提及附件时，必须用全称且与附件标题完全一致。
4. **编号层级统一：** 一级用"一、二、三"，二级用"（一）（二）（三）"，三级用"1. 2. 3."，四级用"（1）（2）（3）"。
5. **段落完整性：** 每段有且仅有一个中心意思，段首句为该段主旨句。
6. **首尾呼应：** 指示性通知的第一段（依据）和最后一段（督查）形成闭环。
