# 文种辨析速查表

## 一页纸判断树

```
要发公文 → 对象是谁？
│
├─ 上级（有隶属）→ 请示 / 报告
│
├─ 下级（有隶属）→ 什么功能？
│   ├─ 答复请示 → 批复
│   ├─ 表彰/批评/传达情况 → 通报
│   ├─ 重大不可逆决策 → 决定
│   ├─ 依法强制执行 → 命令
│   ├─ 指导性建议 → 意见
│   └─ 部署/发布/转发/告知/任免 → 通知 ✓
│
└─ 不相隶属 → 函
```

## 快速判断口诀

| 问自己 | 答案 | 文种 |
|---|---|---|
| 是要求"做"还是要求"知道"？ | 做 | 通知 |
| 是要求"做"还是要求"知道"？ | 知道（表彰/批评/传达） | 通报 |
| 这件事可以被后续文件修改吗？ | 可以 | 通知 |
| 这件事可以被后续文件修改吗？ | 不可以（终局） | 决定 |
| 是主动发文还是答复请示？ | 主动 | 通知 |
| 是主动发文还是答复请示？ | 答复 | 批复 |
| 收文方必须执行还是参照？ | 必须 | 通知 |
| 收文方必须执行还是参照？ | 参照 | 意见 |
| 有隶属关系吗？ | 有 | 通知（下行） |
| 有隶属关系吗？ | 无 | 函 |
