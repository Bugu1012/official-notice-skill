# 通知改写提示卡

## 改写前确认

- [ ] 通知类型已确认（7种之一）
- [ ] 语气档位已确认（强/中/弱）
- [ ] 事由台账已建立
- [ ] 文种已确认（确实是通知，不是通报/决定/意见/函）

## 结构检查

- [ ] 指示性：依据→总要求→分任务→保障→督查，每段职责清晰
- [ ] 发布性：正文是"发布令"，未展开附件内容
- [ ] 批转/转发性：正文不超过3句，未展开论述
- [ ] 会议：时间/地点/内容/人员/要求五要素齐全
- [ ] 任免：只有任免事项，无背景/希望/要求
- [ ] 事务性：事由+事项+要求，未过度渲染

## 语气检查

- [ ] 强部署档：有主体+动作+时限，非空泛"要高度重视"
- [ ] 中要求档：无"务必""严禁"等强部署词
- [ ] 弱告知档：无部署口吻，只有告知
- [ ] 称谓一致（不混用"各地区"和"各省"）

## 套话检查（成组出现才改）

- [ ] 万能意义铺垫（"为进一步推动……的发展"）
- [ ] 空泛背景堆叠（"面临新形势新任务新要求"）
- [ ] 三连套话（"高度重视、统一思想、提高认识"）
- [ ] 无主体部署（"要切实……"无具体主体）
- [ ] 万能结尾（"为推动……贡献力量"）
- [ ] 机械排比（强凑三项对仗）

## 格式检查

- [ ] 标题：发文机关+关于+事由+的+通知
- [ ] 主送机关：全称，位置正确
- [ ] 附件标注：格式正确（"附件：1.……"）
- [ ] 结语：匹配通知类型
- [ ] 落款：发文机关署名+成文日期

## 零编造检查

- [ ] 未添加用户未提供的文件号
- [ ] 未添加用户未提供的数据
- [ ] 未添加用户未提供的人名
- [ ] 未添加用户未提供的时间
- [ ] 〔待补〕标记保留
