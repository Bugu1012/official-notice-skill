# 通知采集指南

gov.cn 及各部委网站公开通知的采集方法、CSV 格式规范、采集建议。

---

## 一、gov.cn 搜索 API 使用方法

### 1.1 政策文件库

中国政府网政策文件库是主要采集来源：

- 入口：`https://www.gov.cn/zhengce/zhengceku/`
- 可按发文机关、文件类型、发布日期筛选。
- 通知类文件在"文件类型"中选择"通知"。

### 1.2 搜索接口

gov.cn 搜索使用以下 URL 模式：

```
https://sousuo.www.gov.cn/search-gov/data?t=zhengcelibrary&q={关键词}&timetype=timeqb&mintime=&maxtime=&sort=score&sortType=1&searchfield=title&pcodeJiguan=&childtype=&subchildtype=&tsbq=&pubtimeyear=&puborg=&pcodeYear=&pcodeNum=&filetype=&p={页码}&n={每页条数}&inpro=&bmfl=&dup=&orpro=
```

参数说明：

| 参数 | 说明 | 示例值 |
|---|---|---|
| t | 搜索范围 | zhengcelibrary（政策文件库） |
| q | 搜索关键词 | 通知 |
| timetype | 时间类型 | timeqb（全部时间） |
| sort | 排序方式 | score（相关度）/ pubtime（时间） |
| p | 页码（从 0 开始） | 0, 1, 2... |
| n | 每页条数 | 20 |
| filetype | 文件类型 | 通知 |
| puborg | 发文机关 | 国务院/国务院办公厅/教育部 |

### 1.3 响应格式

返回 JSON，核心字段：

```json
{
  "searchVO": {
    "listVO": [
      {
        "title": "文件标题",
        "url": "全文URL",
        "puborg": "发文机关",
        "pcodeJiguan": "发文字号",
        "pubtime": "发布时间戳",
        "filetype": "文件类型"
      }
    ],
    "p": "当前页",
    "n": "每页条数",
    "total": "总条数"
  }
}
```

### 1.4 注意事项

- 接口可能有频率限制，建议每次请求间隔 2-3 秒。
- 部分结果为 JS 渲染页面，需检查实际内容是否可获取。
- 标题中可能含 HTML 标签（如 `<em>`），需清洗。
- 时间戳为 Unix 毫秒，需转换为 YYYY.MM.DD。

## 二、采集脚本说明

### 2.1 基本流程

```
1. 构造搜索 URL（按类型/机关/时间范围）
2. 发送 GET 请求，获取 JSON
3. 解析 listVO 数组
4. 逐条提取字段
5. 写入 CSV
6. 翻页（p+1），重复 2-5
7. 去重（按 URL）
8. 人工抽检（随机 10% 验证 URL 可访问）
```

### 2.2 请求头

```
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
Accept: application/json
Referer: https://www.gov.cn/
```

### 2.3 错误处理

| 错误 | 处理 |
|---|---|
| HTTP 429 | 等待 30 秒后重试，最多 3 次 |
| HTTP 403 | 更换 User-Agent 或等待 |
| JSON 解析失败 | 记录原始响应，跳过该页 |
| URL 不可访问 | 标记备注"链接失效"，保留记录 |
| 重复条目 | 按 URL 去重 |

### 2.4 采集节奏

- 每次采集不超过 200 条（10 页 × 20 条）。
- 批次间间隔 5 分钟。
- 单次采集总时长控制在 30 分钟内。
- 记录采集日志（时间、关键词、条数、成功率）。

## 三、CSV 格式规范

### 3.1 字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 序号 | 整数 | 是 | 自增，从 1 开始 |
| 标题 | 文本 | 是 | 完整标题，含书名号 |
| 发文字号 | 文本 | 否 | 如"国发〔2026〕1号"，缺失留空 |
| 类型 | 枚举 | 是 | 发布性/指示性/批转性/转发性/会议/任免/事务性 |
| 来源 | 文本 | 是 | 统一填 gov.cn 或具体部委域名 |
| URL | 文本 | 是 | 全文链接 |
| 发布日期 | 文本 | 是 | 格式 YYYY.MM.DD |
| 发文机关 | 文本 | 是 | 机关全称 |
| 备注 | 文本 | 否 | 补充说明 |

### 3.2 编码和格式

- 编码：UTF-8（带 BOM 或不带均可，推荐不带）。
- 分隔符：英文逗号。
- 含逗号/引号的字段用英文双引号包裹。
- 换行符：LF 或 CRLF 均可。
- 首行为表头。

### 3.3 类型判定规则

采集时需人工或半自动判定通知类型：

| 标题特征 | 判定类型 |
|---|---|
| "关于印发《……》的通知" | 发布性 |
| "关于……的通知"（部署工作） | 指示性 |
| "批转……的通知" | 批转性 |
| "转发……的通知" | 转发性 |
| "关于召开……的通知" | 会议 |
| "关于……任免的通知" / "关于……任职的通知" | 任免 |
| 其他事务性告知 | 事务性 |

## 四、各部委网站采集建议

### 4.1 推荐来源

| 部委 | 网址 | 通知特点 | 采集建议 |
|---|---|---|---|
| 国务院办公厅 | gov.cn | 普发性、权威性最高 | 优先采集 |
| 教育部 | moe.gov.cn | 指示性多，教育系统 | 按栏目采集 |
| 工信部 | miit.gov.cn | 发布性+指示性 | 政策文件栏目 |
| 财政部 | mof.gov.cn | 发布性+事务性 | 通知公告栏目 |
| 人社部 | mohrss.gov.cn | 任免+指示性 | 人事信息栏目 |
| 生态环境部 | mee.gov.cn | 指示性+转发性 | 政策文件栏目 |
| 住建部 | mohurd.gov.cn | 指示性+事务性 | 文件通知栏目 |
| 交通运输部 | mot.gov.cn | 指示性+会议 | 政策文件栏目 |

### 4.2 采集优先级

1. **P0**：国务院办公厅通知（覆盖全部 7 种类型）
2. **P1**：教育部、工信部、财政部（补充指示性和发布性）
3. **P1**：人社部（补充任免类，当前仅 3 条）
4. **P2**：其他部委（补充多样性）
5. **P3**：省级政府网站（补充基层视角）

### 4.3 各部委采集注意

- 部分部委网站使用 JS 动态加载，需浏览器渲染或找到 API 接口。
- 部分网站有反爬措施，需控制频率。
- 优先采集 PDF/HTML 全文可访问的条目。
- 记录采集时的网站栏目路径，便于后续复查。
- 党委系统通知（如中办通知）通常不在公开网站，标注为"不可采集"。

## 五、质量控制

### 5.1 采集后检查

| 检查项 | 标准 |
|---|---|
| URL 可访问 | 随机抽检 10%，可访问率 > 95% |
| 类型标注 | 全量人工复核（或双人交叉） |
| 标题完整 | 无截断、无 HTML 残留 |
| 日期格式 | 统一 YYYY.MM.DD |
| 去重 | 按 URL 去重，无重复 |
| 序号连续 | 1-N 无跳号 |

### 5.2 增量更新

- 每月检查一次 gov.cn 新增通知。
- 新条目追加到 CSV 末尾，序号续编。
- 失效 URL 不删除，在备注中标注"链接失效（YYYY.MM.DD 确认）"。
- 每次更新记录采集日志。
