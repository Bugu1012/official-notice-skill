# 通知起草模板

## 一、指示性通知模板

```
〔发文机关〕关于〔事由〕的通知

〔主送机关〕：

〔依据段〕为深入贯彻落实〔会议/文件/批示〕精神，〔进一步加强/切实做好/全面推进〕〔工作领域〕工作，现就有关事项通知如下。

一、总体要求

〔指导思想/基本原则/主要目标〕

二、重点任务

（一）〔任务名称〕。〔责任主体〕要〔具体动作〕，〔时限〕前完成〔标准〕。

（二）〔任务名称〕。〔责任主体〕要〔具体动作〕，〔时限〕前完成〔标准〕。

（三）〔任务名称〕。〔责任主体〕要〔具体动作〕，〔时限〕前完成〔标准〕。

三、组织保障

（一）加强组织领导。〔具体安排〕。

（二）强化资金保障。〔具体安排〕。

（三）加强督促检查。〔检查方式/考核/问责〕。

〔发文机关署名〕
〔成文日期〕
```

## 二、发布性通知模板

```
〔发文机关〕关于印发《〔规章/制度/办法名称〕》的通知

〔主送机关〕：

《〔名称〕》已经〔审议通过方式〕，现予印发，请认真贯彻执行。

〔可选：施行日期/执行要求〕

附件：《〔名称〕》

〔发文机关署名〕
〔成文日期〕
```

## 三、批转性通知模板

```
〔发文机关〕批转〔下级机关〕关于〔事由〕〔文种〕的通知

〔主送机关〕：

〔发文机关〕同意〔下级机关〕《关于〔事由〕的〔文种〕》，现转发给你们，请认真贯彻执行。

〔可选：补充要求，不超过1句〕

附件：〔下级机关〕关于〔事由〕的〔文种〕

〔发文机关署名〕
〔成文日期〕
```

## 四、转发性通知模板

```
〔发文机关〕转发〔上级/同级机关〕关于〔事由〕〔文种〕的通知

〔主送机关〕：

现将〔上级/同级机关〕《关于〔事由〕的〔文种〕》转发给你们，请认真贯彻执行。

〔可选：结合本地区/本部门实际的要求，不超过1句〕

附件：〔上级/同级机关〕关于〔事由〕的〔文种〕

〔发文机关署名〕
〔成文日期〕
```

## 五、会议通知模板

```
〔发文机关〕关于召开〔会议名称〕的通知

〔主送机关〕：

经研究，决定召开〔会议名称〕。现将有关事项通知如下：

一、会议时间

〔年〕年〔月〕月〔日〕日（星期〔X〕）〔上午/下午〕〔时间〕。

二、会议地点

〔具体地点〕。

三、会议内容

〔议题/主要议程〕。

四、参会人员

〔参会范围〕。

五、有关要求

（一）请参会人员于〔报到时间〕前到〔报到地点〕报到。

（二）请〔相关单位〕提前准备〔材料〕。

（三）联系人：〔姓名〕，电话：〔电话〕。

〔发文机关署名〕
〔成文日期〕
```

## 六、任免通知模板

```
〔发文机关〕关于〔人名〕等职务任免的通知

〔主送机关〕：

经〔决定方式〕研究决定：

任命〔人名〕为〔职务〕。

免去〔人名〕的〔职务〕。

〔发文机关署名〕
〔成文日期〕
```

## 七、事务性通知模板

```
〔发文机关〕关于〔事由〕的通知

〔主送机关〕：

〔事由段〕根据〔依据〕/因〔原因〕，〔现将有关事项通知如下/现就……事宜通知如下〕。

〔事项段〕〔具体告知内容〕。

〔要求段（可选）〕〔需要配合的事项〕。

特此通知。

〔发文机关署名〕
〔成文日期〕
```
