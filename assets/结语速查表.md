# 结语速查表

| 通知类型 | 规范结语 | 说明 |
|---|---|---|
| 指示性通知 | 以要求收束（"各地区各部门要……"）或"特此通知" | 强部署档通常以要求收束 |
| 发布性通知 | 无独立结语（以"请认真贯彻执行"收束） | 执行要求即结语 |
| 批转性通知 | 无独立结语（以"请认真贯彻执行"收束） | 同上 |
| 转发性通知 | 无独立结语（以"请认真贯彻执行/请结合实际落实"收束） | 同上 |
| 会议通知 | "特此通知"或以要求收束（"请按时参加"） | 视正式程度 |
| 任免通知 | 无结语 | 以任免事项收束 |
| 事务性通知 | "特此通知" | 标准结语 |

## 禁用结语

| 禁用 | 原因 | 替代 |
|---|---|---|
| "请批示" | 上行文结语，不用于下行通知 | "请认真贯彻执行" |
| "妥否，请批示" | 请示结语 | 删除 |
| "请予支持为盼" | 函结语（平行文） | "请认真贯彻执行" |
| "特此函告" | 函结语 | "特此通知" |
| "请研究函复" | 函结语 | 删除 |
| "为……贡献力量" | 宣传性结尾 | 删除 |
