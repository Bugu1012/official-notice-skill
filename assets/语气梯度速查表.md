# 语气梯度速查表

## 三档速查

| 档位 | 适用类型 | 标志词（可用） | 禁用词 | 典型句式 |
|---|---|---|---|---|
| **强部署** | 指示性通知 | 要、切实、确保、严格、不得、严禁、务必、坚决 | — | "各地区各部门要……""确保……落到实处" |
| **中要求** | 发布/批转/转发/会议 | 请、认真、遵照、按时、结合、切实 | 务必、严禁、坚决 | "请认真贯彻执行""请按时参加" |
| **弱告知** | 任免/事务性 | 特此、现予、经研究决定、予以 | 要、切实、确保、务必 | "特此通知""经研究决定" |

## 套话判断公式

**合法部署语言** = 具体主体 + 具体动作 + 可验证标准

**套话** = 无主体/泛化主体 + 无具体动作 + 放入任何文件都成立

| 判断 | 示例 | 理由 |
|---|---|---|
| ✓ 合法 | "各省要于2026年底前完成排查" | 有主体+动作+时限 |
| ✓ 合法 | "严格实行一票否决" | 有具体制度 |
| ✗ 套话 | "要高度重视、统一思想、提高认识" | 三连无具体动作 |
| ✗ 套话 | "确保各项工作落到实处、取得实效" | 无主体无标准 |
| ✗ 套话 | "面临新形势新任务新要求" | 万能背景 |
