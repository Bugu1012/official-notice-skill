# 内部核验附注模板

```
# 内部核验附注

通知类型：〔7种之一：指示性/发布性/批转性/转发性/会议/任免/事务性〕
文种辨析：〔确认/待确认（说明原因）〕
语气档位：〔强部署/中要求/弱告知〕
三关键词评分：〔总分/100〕
  - 站位：〔/25〕
  - 逻辑：〔/25〕
  - 内容：〔/25〕
  - 语气：〔/15〕
  - 格式：〔/10〕

未验证项：
1. 〔待补/待确认事项〕

候选核定项：
1. 〔内容明确但是否被用户确认尚不明确的事项〕

处理说明：
已按通知类型选择对应结构；语气档位与类型匹配；未添加用户未提供的事实和数据。
批转/转发性通知正文未超过3句。/ 任免通知未添加背景和要求。
```

## 使用说明

- 每次交付通知净稿时附带本附注
- 用户要求审查时，附注中的"未验证项"是重点回查对象
- 三关键词评分低于70分时，附注中说明低分原因和改写方向
